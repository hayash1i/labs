Датасет: Bank Marketing (`bank.csv`)
Задача: Бинарная классификация - предсказать, откроет ли клиент срочный депозит

# Описание датасета
Датасет содержит данные телефонных маркетинговых кампаний португальского банка. Каждая строка - один клиент со следующими группами признаков:
- Демография: `age`, `job`, `marital`, `education`
- Кредитная история: `default`, `housing`, `loan`, `balance`
- Параметры контакта: `contact`, `day`, `month`, `duration`, `campaign`, `pdays`, `previous`, `poutcome`
- Целевая переменная: `deposit` (`yes`/`no`) - открыл ли клиент срочный депозит
Размер: 11 162 строки, 17 столбцов.
Источник: [Bank Marketing Dataset на Kaggle](https://www.kaggle.com/datasets/janiobachmann/bank-marketing-dataset)

# Постановка бизнес-задачи
Банк проводит телефонные маркетинговые кампании. Каждый звонок стоит денег, а большинство клиентов отказываются. Цель - построить модель, которая предсказывает вероятность согласия клиента, чтобы звонить только «перспективным» клиентам и экономить бюджет кампании.

# Что сделано
1. Загружен и осмотрен датасет
2. Удалены столбцы `day`, `month`, `duration` — последний как источник утечки данных
3. Проведён разведочный анализ: `groupby` по образованию, boxplot «возраст vs отклик»
4. One-Hot Encoding категориальных признаков, разбиение на train/test со `stratify`
5. Масштабирование числовых признаков (scaler обучался только на train)
6. Обучен `RandomForestClassifier`, оценён через `accuracy_score`

# Результаты
- Accuracy модели: ~ 80–85 %
- Ключевые драйверы отклика: `poutcome` (успех прошлой кампании), `contact` (мобильный контакт), `housing`/`loan` (отсутствие кредитов), `balance`, `age`
- Бизнес-эффект: таргетинг по скору модели сокращает бюджет кампании в 1.5–2 раза без потери большинства будущих депозитов
